**Tools:** Excel | Power Query | Pivot Tables | Pivot Charts | Healthcare Analytics

### 📌 Project Overview

This project analyzes pharmacy spend trends using Excel to demonstrate how healthcare organizations and pharmacy benefit teams can monitor high-cost medications, brand utilization, and prior authorization impact.

The dataset required cleaning and transformation using Power Query, including duplicate removal, missing values, inconsistent tier labels, and formatting issues. After preparation, PivotTables and PivotCharts were used to summarize findings and present insights in an executive-style analysis.

### 🎯 Key Business Questions

1. Which medication tiers drive the highest pharmacy spend?  
2. How much spend is concentrated in brand vs generic medications?  
3. What portion of spend requires prior authorization?  
4. Which drugs are the top pharmacy cost drivers?

### 🔍 Key Insights

- Total pharmacy spend analyzed was **$55K**
- **Tier 3 medications drove $52K** of total spend, indicating specialty/high-cost therapies as the largest expense area
- **Brand drugs accounted for 99.8%** of spend, showing limited generic utilization in the sample
- **Prior authorization medications represented $52K**, highlighting utilization management opportunities
- **Humira, Skyrizi, Dupixent, Ozempic, and Jardiance** were the top pharmacy cost drivers

### 🛠 Data Preparation

Using Power Query, the dataset was cleaned through:

- Standardizing drug tier labels
- Correcting inconsistent text values
- Removing duplicate records
- Handling missing fields
- Formatting numeric spend values
- Preparing data for PivotTable analysis
